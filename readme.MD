# Penguin Store — Reto 01

Proyecto correspondiente al Reto 1 del nivel final.

El objetivo es construir una tienda online y un panel administrativo utilizando:

- Node.js
- Express
- MongoDB
- Pug
- Renderizado del lado servidor
- Sesiones y cookies HTTP-only

## Restricción principal

La tienda pública no utilizará JavaScript en el frontend.

Las vistas serán generadas desde el servidor.
